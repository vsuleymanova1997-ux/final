# Elm City Tutoring Corps — org profile

Elm City Tutoring Corps (ECTC) is a Yale undergraduate service org that places
volunteer tutors with New Haven public school students for weekly 1-on-1 sessions.
~45 active volunteers, ~30 tutee families, run entirely by a 4-person e-board
(Director, Treasurer, Volunteer Coordinator, Family Liaison) with no paid staff.

This project is a synthetic stand-in for a real e-board's workload — the data,
names, and dollar amounts are invented, but the workflow (dues/hours tracking,
reimbursements, tutee matching, volunteer FAQs) mirrors what a real ~40-person
Yale service org actually deals with by hand in spreadsheets and email.

Funding: a mix of Dwight Hall seed funding and a small UOFC (Undergraduate
Organizations Funding Committee) grant, both already disbursed into ECTC's
checking account for the semester. The Treasurer approves reimbursements against
that fixed budget — there is no separate request-for-funds step in this tool.
